# 第四批歌词与个性化：独立代码审查交接

审查范围：草稿 PR #8（分支 `feat/b4-lyric-layer-positioning`）。
不合并到 `main`，也不把编译通过视为整批真机验收完成。

## 功能边界

- L05：原有经典、沉浸、黑胶布局及分区比例、封面缩放、图层显隐与顺序保留。
- 四类可编辑节点：封面、歌曲信息、歌词视图、播放控件。
- 每个节点有独立的、受限的 X/Y 位移（最大 ±20% 对应区域宽度、±32dp）及锁定。
- 各节点缩放 70%–135%；封面和歌曲信息的相互遮挡层级可切换。
- 预览与真实播放器复用位移换算；草稿拖动完成后才写入一次撤销历史。
- 保存、取消、24 步撤销 / 重做、复制预设及恢复默认沿用现有事务逻辑。
- 持久化 JSON 升级 schema v4；旧 v2/v3 不带新增字段时保持默认位置与大小。
- Android 8–11：远处歌词用文本阴影模糊回退，封面背景用低分辨率缓存位图模糊。
- Android 12+ 继续使用图层 blur；图片私有存储、EXIF 旋转及缺失回退沿用原实现。

**尚非绝对自由画布**：四节点仍受经典 / 宽屏 / 沉浸的布局分区及滚动容器约束，
不能任意跨屏重叠，歌词与播放控件暂无独立可调遮挡层级。
审查时应重点确认这种受限编排是否满足 L05 原始验收要求，不能只看控件数量。

## 自动化审查入口

- `.github/workflows/ci.yml`：前端、文档、桌面和 Rust 主线检查。
- `.github/workflows/android-native-verify.yml`：原生 Kotlin JVM、
  Lint、Debug APK / 测试 APK 构建、API 35 模拟器离线 UI 检查。
- `NativeLyricPresetModelsTest.kt`：移动、锁定、缩放、重叠顺序、
  JSON 旧版兼容、草稿回滚与复制。
- `NativeLegacyBlurTest.kt`：小位图像素模糊、边界条件。
- `NativePersonalizationUiTest.kt`：独立编辑交互、保存与重读；
  需核实 API 35 新增四图层交互及各机型位置是否一致。

CI 状态必须以最新提交的 GitHub Actions 结果为准。
只有工作流完整成功才能把相应测试标记为通过；
构建完成但未经安装的 APK 不能代替设备验收。

## 真机验收仍需补证据

1. Android 8–11、12+ 的模糊效果与帧率、持续滚动、切歌表现。
2. 竖屏、横屏、平板上的四图层手柄，移位与缩放边界、
   触控命中区、标题极长、无封面、无歌词。
3. 四图层的显隐、锁定、缩放、撤销 / 重做、取消、复制、
   冷启动和应用进程重建后的状态；离线预览与真实播放器对照。
4. 真实 `content://` 图片 URI 导入、EXIF 旋转、无效文件不覆盖旧图、
   缺失文件回退、四种背景与字体 / 配色组合。
5. 真实音乐的逐字同步、翻译、罗马音、手动滚动后恢复跟随，
   暂停、拖进度、快切歌曲以及性能。
6. 绝对自由画布与跨分区层级未实现，如验收定义要求，应继续开发再关闭 L05。

审查建议先核查编译与模拟器测试，再检查布局几何约束、
无障碍语义及持久化事务。未进行真实账号写入或正式发布。
